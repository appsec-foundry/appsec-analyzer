Focused security analysis through the installed AppSec Analyzer CLI.

appsec-analyzer analyze-threats "Question" --path src/api
appsec-analyzer analyze-threats "Question about this change" --staged
appsec-analyzer analyze-threats --worktree
appsec-analyzer analyze-threats "Design question" --design
appsec-analyzer analyze-threats --design-file design.md
appsec-analyzer analyze-threats --mr https://gitlab.example/team/app/-/merge_requests/42
appsec-analyzer analyze-threats --pr https://github.com/team/app/pull/42

Use --context FILE repeatedly for repository documents, --no-context to disable
automatic discovery, and --preview to inspect selection without a model call.
MR/PR preview still retrieves metadata and source. --non-interactive never prompts.

Model-backed analysis uses Claude CLI and sends selected context to the host.
--max-budget-usd defaults to USD 1 per call, not a total-job budget guarantee.
Run appsec-analyzer analyze-threats --help for all arguments and limits.
