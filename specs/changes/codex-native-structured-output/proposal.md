# Native structured Codex responses

The previous outer schema guaranteed only that `payload_json` was a string. The adapter parsed its contents a second time, so an otherwise completed turn could still contain malformed or ambiguous inner JSON. The stored diagnostic identifies this failure category; raw responses are deliberately not retained and the precise malformed contents cannot be reconstructed.

Compile the supplied analysis schema into a closed native JSON contract under `payload`. Represent optional fields with explicit presence, dynamic maps with key/value entries, and unconstrained JSON objects with an entries wrapper. Preserve absence separately from explicit null. Resolve only references in the supplied contract; reject duplicate object members, collisions with declared fields, and unions with different decoded meanings. Bound decoding and compilation, count the wire schema and trusted instructions against the request byte limit, and never fall back to parsing an embedded JSON string.

The native schema replaces the redundant canonical schema previously copied into instructions. Trusted role instructions and controller-supplied semantic rules remain. Serialize the wire schema compactly and reserve its full byte size before source batching.

The controller continues to validate the canonical result, exact source quotations, source scope, permissions, and execution limits. Invalid model data cannot authorize reads or weaken acceptance. Diagnostics retain fixed failure categories without raw model output. The full live eight-phase assessment remains unqualified.
