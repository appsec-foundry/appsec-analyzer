# Independent exploitation evidence

The user requested implementation of the reviewed verifier recommendations and chose direct work on main. This change restores REQ-008's evidence requirement at the independent review boundary. It adds no new model role, source authority, read allowance, verdict, or finding field.

At thorough depth, for a finding marked confirmed exploitable with a mechanism trace, a verified review cites its input, sink, and control location. The existing source checks validate those citations against the review's authorized source and served ranges. An omitted role returns a correction request within the existing job limits; an exhausted review follows the existing ambiguous fallback. This applies at every severity and allows one source location to support several roles.

At thorough depth, for confirmed exploitation without a mechanism trace, the reviewer records access, effect and controls with reasons and indices into its own evidence. This restores the same evidence requirement for authorization, disclosure and configuration claims without imposing an artificial data-flow trace. It uses the existing review exchange and correction limits. The optional field remains in the internal review receipt and is not a new published finding field.

The model still judges whether the source establishes the claimed connection, access, effect and control failure. Citation completeness is no semantic proof. Unproven findings and verified insecure practices retain their existing treatment. The user authorized completing these existing verification rules without adding model rounds.

Quick and standard omit the extra prompt instructions and schema fields as well as the new validation requirements; their existing review checks remain. The built-in Claude profile explicitly retains Sonnet for the thorough evidence verifier, with operator overrides preserved. Documentation and depth-routing tests cover this decision. Additional token use has not been measured.
